🏢 Human Resources Management System (HRMS)

This project is a Human Resources Management System developed to streamline HR operations, including employee management, recruitment, payroll, and reporting. The system provides separate access for administrators and applicants, ensuring secure and efficient handling of HR processes.

🌟 Project Overview

The HRMS platform aims to:

Automate HR processes such as employee records, leave management, and payroll.

Support recruitment by managing job openings and applications.

Provide insights through dashboards and visualizations.

Ensure secure access for administrators and applicants.

⚙️ Features
1. Authentication and Administration

Admin Login: Secure login system for authorized administrators.

Applicant Login: Allows candidates to create accounts, log in, and apply for jobs.

2. Company Information Management

Company Profile: Administrators can display and manage company information.

3. Dashboard (Dashboard.java)

The dashboard provides HR insights at a glance:

Total Employees: Displays the total number of employees in the system.

Total Leaves: Statistics on submitted leave requests.

Total Employee Salaries: Calculates total salary expenditure.

Employee Distribution by Department: Pie chart visualization.

Employee Distribution by Gender: Bar chart visualization.

Administrator Information: Details of all administrators, including roles and permissions.

Employees on Leave: List of employees currently on leave with duration.

4. Employee Management

Add Employee: Capture employee details including personal info, job role, and department.

Update Employee: Modify employee information like contact details, job title, and schedule.

Delete Employee: Remove employees while ensuring data integrity.

Employee Training Records: Track trainings attended, dates, durations, and completion status.

Monthly Hours Worked: Calculate total hours worked per month per employee.

Leave Evaluation: Assess frequency and duration of leaves to improve leave management.

5. Departments and Positions

CRUD Operations: Create, read, update, and delete departments to manage organizational structure.

6. Job Openings and Applications

Job Openings: Create, update, and remove job postings, including title, description, and requirements.

Applications: View and manage applications received from candidates, including applicant info, submission date, and status.

7. Applicant Space

Applicant Login & Registration: Applicants can create accounts, log in, and apply for jobs.

Application Tracking: View the status of submitted applications.

🛠️ Technology Stack

Backend: Java, Spring Boot

Frontend: (Assumed) JSP/Thymeleaf / HTML / CSS / JavaScript

Database: MySQL / H2 for development

Build Tool: Maven
